# Amoovi

Amoovi is an experimental concept for a next-generation, browser-based video editing platform. It combines a responsive editing workspace, AI-assisted creative flows, and integrations with modern storage and generation services.

## Getting started

```bash
pnpm install # or npm install / yarn install
pnpm run dev
```

Then open <http://localhost:5173>.

## Features showcased

- **Cross-device layout** — Desktop-first timeline with responsive media bin, preview monitor, and AI director panels designed to adapt to tablets and phones.
- **TurboProxy workflow** — Media bin concept illustrates proxy generation, remote storage linking, and clip organization.
- **Cinematic timeline** — Stylized mock timeline inspired by professional editors with multi-track representation and modern transport controls.
- **AI-first editing** — Command palette for text or voice-driven edits, recent prompt history, and placeholders for connecting GPT-5, Claude, Gemini, Runway, ElevenLabs, and more.
- **Creation hub** — Generation panel highlighting text-to-video, AI audio, and template-driven storytelling across provider integrations.
- **Dark mode design system** — Tailwind-powered theming with elevated surfaces, glassmorphism, and accessible contrast.

> ⚠️ This repository currently focuses on visual scaffolding and interaction patterns. Actual media processing, real-time editing engines, and AI orchestration are out of scope for this concept build.
